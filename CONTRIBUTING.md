# Contributing

## Build
- AGP 9.4 (built-in Kotlin), Kotlin 2.4, compileSdk 37 (OkHttp 5.5 requires it), minSdk 29, JDK 17+.
- `./gradlew testDebugUnitTest :app:assembleRelease :wear:assembleRelease`. `build.ps1` does the same with the SDK
  and Gradle home kept in `.tools/` (gitignored) and copies the APK to `AllFather.apk`.
- Phone and watch apps share the applicationId (`app.allfather`) and must share the signing key.
- R8 keeps line numbers; every release build gzips its mapping into `.tools/mappings/<app|wear>-<versionCode>-<map id>.txt.gz`.
- Install with `adb install -r …` and then `adb shell cmd package compile -m speed app.allfather`: a plain install
  leaves the app interpreted until the phone's idle dexopt job, and it feels laggy.
- Baseline Profile: the `:baselineprofile` module (`nonMinifiedRelease` build type) regenerates
  `app/src/main/baseline-prof.txt` on an unlocked, idle phone. Don't run `connectedAndroidTest`: it uninstalls the
  app (sign-in, push and sharing keys go with it).
- Tests: `app/src/test` (JVM, JUnit; one per non-trivial parser). `net/HermesClientTest` drives the WebSocket
  against a mockwebserver3 fake dashboard under Robolectric (`Store(ctx, encrypted = false)`, no AndroidKeyStore
  there; `@ConscryptMode(OFF)`, else javax.crypto breaks for the BouncyCastle tests sharing the JVM). Robolectric's
  Android jars go to `.tools/robolectric-m2`. Tests that read string resources run under Robolectric with
  `application = HermesApp::class`.
- Strings: English in `res/values/strings_*.xml`, Spanish in `res/values-es/`. Outside Compose use `tr(...)` /
  `trPlural(...)` (`HermesApp.kt`). Text sent to the model stays English in code.
- Background work uses JobScheduler (no WorkManager): `adb shell cmd jobscheduler run -f app.allfather 7101`
  (hourly) / 7102 (calendar trigger).
- Libraries ship no sources jar: read overloads from the compiler error, or unzip the aar from the Gradle cache.

## Code map
- `HermesApp.kt`: `AppGraph`, process-wide state. `net/`: `HermesClient` (cookie REST + JSON-RPC WebSocket,
  profile scoping, OAuth bearer, Cloudflare/custom headers) and `Store` (multi-dashboard, Keystore-encrypted).
- `chat/`, `sessions/`, `tasks/`, `bots/`, `settings/`, `login/`: one `*State` + `*Screen` per feature.
- `share/` (per-channel X25519 crypto and REST for phone/location/health), `phone/`, `location/`, `health/`,
  `alerts/` (notices worked out on the phone), `push/` (FCM, E2E), `voice/` (dictation, read aloud, Gemini Live,
  wake phrase), `assist/` (system assistant), `control/` (phone control: accessibility service, actions, bubble),
  `watch/` + the `:wear` module, `sharesheet/`, `launcher/` (shortcuts, tile, widget), `ui/` (theme, shell,
  components, Lucide icons generated by `scripts/lucide.py`).
- The host plugin's protocol keeps its upstream names (`/api/plugins/conduit_push/*`, `conduit_*` payload keys,
  `conduit-*` crypto labels): don't rename them, the plugin wouldn't answer.

## Compose and library gotchas
- mikepenz markdown 0.46: pass `rememberMarkdownState(text, retainState = true)` or each streamed delta blanks
  the reply and breaks auto-scroll. Tables go through `wrappingTable`. A lone `~` pairs into strikethrough
  (`escapeTildes`). `Markdown` defaults to `fillMaxSize`: pass `fillMaxWidth()`.
- Relative times (`DateUtils`) follow the phone's locale: all go through `ui/components/ago()`.
- KaTeX and Mermaid are bundled in `app/src/main/assets/web` (no CDN); `HtmlBlock` blocks the network. To update,
  take the files from the npm tarball and check its `sha512` against the registry.
- MediaPlayer: `prepareAsync()` + `setOnPreparedListener`, and stop with `release()` alone (`stop()` throws while
  preparing). Gemini Live's speech goes through a queue written on its own thread, or barge-in lags.
- App widgets inflate only allowed classes (LinearLayout, FrameLayout, TextView, ImageView…): a plain `<View>`
  spacer makes launchers show "can't load".
- Google's on-device SpeechRecognizer beeps every time it opens or closes the mic: continuous listening
  (`voice/Wake.kt`) feeds its own AudioRecord through `EXTRA_AUDIO_SOURCE` + `EXTRA_SEGMENTED_SESSION`.
- Gemini Live: each connection needs a fresh single-use token from Hermes; resumption uses the last
  `sessionResumptionUpdate` handle; GoAway hands off to a second socket.
- Health Connect refuses reads from a closed app without READ_HEALTH_DATA_IN_BACKGROUND; its permission screen
  only opens with the manifest's rationale aliases.
- Plugin WebSockets (Kanban `/events`) take a fresh `/api/auth/ws-ticket` per connect (`HermesClient.pluginSocket`).
- Overlays drawn over the chat take every touch through `PredictiveBackLayer`'s `pointerInput(Unit) {}` inside
  the sliding layer, or taps fall through to the chat below.
- Navigation: every screen slid over the chat uses `Motion.page()`. `HermesClient.rest` parses JSON on IO; keep
  heavy decoding off the callers, which run on `graph.scope` (main).
- Kotlin nests block comments: `/*` inside a KDoc opens another comment.
- `var x by …; private set` plus a `fun setX(…)` clash on the JVM: name the function `choose(…)`.
- Inside `Foo().apply { }` a bare `stop()` is Foo's member: write `this@Outer.stop()`.
- Calls: the relay sends `call.requested` as `push_type=voip` with the call in `body.conduit`. Android ignores
  `setTimeoutAfter` on call notifications, so `HermesCalls.ring` stops itself after 45 s.
- `withTimeout` throws TimeoutCancellationException, a CancellationException: a loop that rethrows
  cancellations dies silently on a timeout. `HermesClient.call`/connect use `withTimeoutOrNull … ?: throw IOException`.
- `HermesClient.onConnected` runs in its own coroutine, never inside the connect job, or a drop during it leaves
  the app on "Reconnecting…".
- Progress notifications: a turn cut off by a dashboard restart never sends its `end`; `setTimeoutAfter(15 min)`
  and the relay's 8 h TTL clear them.
- OkHttp WebSocket: a server close (dashboard restart = 1012) arrives as `onClosing`; close back and reconnect
  there, or RPCs hang until their timeout.
- Location batches: `locate_id` sits at the batch's top level, or the host never marks the locate answered.
- A runtime session id only lives on the WebSocket connection that created/resumed it: anything that keeps one
  across reconnects must `session.resume` it when `graph.connectedEpoch` changes.
- `session.create` takes `model`/`provider`/`reasoning_effort` overrides; a `config.set model` right after create
  doesn't reach the fresh agent.
- A `microphone` foreground service is while-in-use: started from the background it crashes. Watch calls run
  `LiveCallService` as `connectedDevice`.
- Watch audio goes as one Data Layer message (< 90 KB); a ChannelClient channel needs its own `CHANNEL_EVENT`
  intent filter.
- Package visibility: `queryIntentActivities` only sees apps declared in `<queries>`.
- Android ICU regex rejects unescaped `{`, `}`, `]` that JVM tests accept: escape them.
- The chats list passes `exclude_sources`, which replaces Hermes' default hidden set: keep `cron,kanban,tool,oneshot`.
- Never create Kanban test tasks on a real board: even triage tasks get specified and dispatched to a worker.
